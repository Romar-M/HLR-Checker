# 📞 HLR Checker

Простая рабочая версия (CLI) для массовой проверки «живости» телефонных номеров из Excel-файла через HLR-запросы.

Поддерживает два режима:

| Режим | Когда включается | Куда ходят запросы |
|-------|------------------|--------------------|
| **Реальный** | в `config.json` задан `api_key` | SMSC.RU (платные HLR) |
| **Демо** | `api_key` пустой | заглушка внутри программы (бесплатно) |

---

## Что делает программа

1. Берёт все `.xlsx`-файлы из папки **`export/`** (временные файлы Excel `~$...` пропускаются).
2. **Сохраняет все исходные данные** (все заполненные столбцы остаются на месте — файл можно загружать обратно).
3. **Удаляет пустые столбцы** — те, в которых под заголовком нет ни одного значения.
4. Автоматически находит столбцы с телефонами (по заголовкам + проверке содержимого).
5. Нормализует номера **прямо в исходных ячейках** — приводит к формату `8XXXXXXXXXX` (`+7...` превращается в `8...`).
6. Проверяет каждый номер (реальный HLR или демо-заглушка).
7. Добавляет справа столбцы:
   - `<имя_колонки>_статус` — статус номера;
   - `<имя_колонки>_оператор` — оператор связи;
   - `<имя_колонки>_регион` — регион регистрации SIM;
   - `проверка` — итог по строке: `активен` / `заблокирован` / `недоступен` / `ошибка формата`.
8. Сохраняет результат в папку **`import/`** с тем же именем файла.

## Быстрый старт (Windows)

1. Установите [Python 3](https://www.python.org/downloads/) и отметьте галочку **«Add Python to PATH»**.
2. Настройте ключ API:
   - скопируйте `config.example.json` в `config.json`;
   - вставьте свой `api_key`:

   ```json
   {
     "api_key": "ВАШ_API_КЛЮЧ"
   }
   ```

   > Для SMSC.RU API-ключ создаётся в личном кабинете: `Настройки → API-ключи`.
   > Если оставить `api_key` пустым — программа будет работать в демо-режиме.

3. Положите исходный `.xlsx`-файл в папку **`export/`**.
4. **Дважды кликните по `start.bat`, либо `start.command` для MAC**.
5. Результат появится в папке **`import/`** с тем же именем.

## API-ключ

API-ключ хранится **в отдельном файле `config.json`** (лежит рядом с `main.py`) и **не попадает в репозиторий**.

- `config.json` — ваш локальный файл с реальным ключом (указан в `.gitignore`).
- `config.example.json` — шаблон без ключа, который можно безопасно публиковать.

Программа при запуске читает ключ из `config.json` и показывает его в замаскированном виде:

```text
[KEY]   API-ключ загружен из config.json: 7a\орi•••J243
```

> ⚠️ Никогда не коммитьте `config.json` с реальным ключом.

## Как работает реальный HLR (SMSC.RU)

Программа использует стандартное HTTP API SMSC.RU:

1. Отправляет запрос:
   ```
   GET https://smsc.ru/sys/send.php?apikey=<ключ>&phones=<номер>&hlr=1&fmt=3
   ```
   В ответе получает `id` HLR-запроса.

2. Опрашивает статус:
   ```
   GET https://smsc.ru/sys/status.php?apikey=<ключ>&phone=<номер>&id=<id>&all=2&fmt=3
   ```
   Ответ содержит оператора, регион и статус номера.

3. Статусы преобразуются в понятный вид:

| Статус SMSC | Вывод |
|-------------|-------|
| `1` | `активен` |
| `3` | `заблокирован` |
| `4` | `недоступен` |
| другое | текст из API / `не определён` |

> HLR-запросы платные и занимают несколько секунд на номер. Программа выводит
> прогресс по каждому номеру в консоль.

## Как определяется оператор и регион

1. **В реальном режиме** оператор берётся из поля `net` ответа SMSC.RU
   (это фактический оператор сети — точнее всего, учитывает перенос номера MNP).
   Если `net` пуст — берётся поле `operator`, и только потом — справочник DEF.

2. **Регион SMSC.RU часто не возвращает** (поле `region` приходит пустым/мусорным).
   Поэтому регион проставляется из **справочника DEF-кодов** (`def_codes.py`).

3. Справочник `def_codes.py` — это запасной (fallback) вариант по первым трём
   цифрам номера после `8`.

> ⚠️ **Важно про точность региона.** С декабря 2013 года в РФ действует
> **MNP (переносимость номеров)**, поэтому DEF-код не гарантирует ни оператора,
> ни регион — номер мог быть перенесён. Для федеральных кодов (Tele2 и др.)
> один DEF-код выдаётся сразу во многих регионах, поэтому в выводе стоит
> значение `Федеральный`. Точный регион регистрации SIM SMSC.RU в HLR-ответе
> не отдаёт.

## Папки

| Папка | Назначение |
|-------|------------|
| `export/` | Сюда кладёте исходные файлы для обработки (`.xlsx`) |

> 2. IMPORT_DIR_NAME = "import"

## Формат номеров

Все корректные номера в выводе приводятся к виду **`8XXXXXXXXXX`** (11 цифр, без `+`, без пробелов и дефисов).

| Вход | Выход |
|------|-------|
| `+7 900 123-45-67` | `89001234567` |
| `8 900 123-45-67` | `89001234567` |
| `+79001234567` | `89001234567` |
| `9001234567` (10 цифр) | `89001234567` |
| `не указан` / `abc` / `123` | остаётся как есть, статус `ошибка формата` |

## Структура проекта

```

├── main.py              # Точка входа: берёт файлы из export/, кладёт в import/
├── hlr_checker.py       # Нормализация + реальный HLR (SMSC) + демо-заглушка
├── def_codes.py         # Справочник DEF-кодов (оператор + регион, fallback)
├── excel_utils.py       # Чтение/запись Excel, поиск колонок, итоги
├── config.py            # Чтение API-ключа из config.json
├── config.json          # API-ключ (локальный, НЕ коммитить)
├── config.example.json  # Шаблон конфига (без ключа, можно коммитить)
├── make_sample.py       # Создание тестового Excel-файла
├── start.bat            # Запуск двойным кликом (Windows)
├── requirements.txt     # Зависимости
├── LICENSE              # Лицензия MIT
├── .gitignore           # Исключения для git
├── export/              # Исходные файлы
├── import/              # Результаты
└── README.md            # Этот файл
```
